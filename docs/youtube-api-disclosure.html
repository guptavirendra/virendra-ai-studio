How Virendra AI Studio requests YouTube access, what it does with the API, and how you can disconnect it.

↗

YouTube API Services are used by Virendra AI Studio in accordance with applicable YouTube API Services Terms of Service and Developer Policies.

01 / THE CONNECTION

You authorize it.
You can revoke it.

The optional integration uses Google's OAuth flow. The operator starts the flow on the machine running the app, and the user signs in to Google and grants or denies the requested permissions. Virendra AI Studio does not ask users to provide their Google password to the app.

OAuth credentials are saved to a local file on the app host (the default filename is youtube_token.json). Keep that file private and out of source control. The token can be used by the app to make authorized requests to YouTube; if a refresh token is issued, the local app can use it to obtain renewed access.

02 / REQUESTED PERMISSIONS

Only the scopes
used by the integration.

https://www.googleapis.com/auth/youtube.upload

Allows the application to upload videos to the authorized YouTube account.

https://www.googleapis.com/auth/youtube.readonly

Allows the application to read YouTube account information, including the authenticated channel details.

The app queries the authenticated channel's name and ID during local authorization setup so the operator can confirm which channel was connected. The project does not request the YouTube Analytics scope.

03 / WHAT THE APP DOES

Built for a
transparent workflow.

  • 01
    Retrieve channel details

    Read the authorized channel's basic identifying details for local setup confirmation.

  • 02
    Upload a video

    Send the rendered video file and user-prepared metadata, including title, description, tags, category, and visibility, to YouTube Data API v3.

  • 03
    Update the workflow

    Process YouTube's upload response to update the local content status. The daily publishing job also logs the returned video ID.

04 / VISIBILITY & PUBLISHING

Private by default
for manual uploads.

Manual uploads default to private, although an upload request can specify a different visibility. Review the visibility for each request before authorizing an upload.

The repository also contains a separate daily Bollywood-news workflow that explicitly uploads publicly. It is disabled by default and only runs when an operator enables and configures the scheduler. When enabled, it is automated and does not use the manual approval step for each generated video. Do not enable it unless you intend to authorize unattended public uploads.

05 / YOUR CHOICES

Disconnect whenever
you need to.

Revoke the app's Google access in your Google Account permissions. Then stop the scheduler if enabled and remove the local OAuth token file from the host where the app runs. Revoking access affects future API calls; it does not remove videos already uploaded. Manage uploaded videos in YouTube Studio.

For more detail about content, tokens, storage, and retention, read the Privacy Policy.
