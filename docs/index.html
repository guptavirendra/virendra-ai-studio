right place.

Practical tools for turning a topic into a polished draft—without hiding the steps between.

01✦

Hindi, AI-assisted writing

Generate Hindi script and SEO drafts. When OpenAI is configured, the topic and prompt are sent to its API; a built-in template is used when AI is unavailable.

SCRIPT + SEO
02≋

Local video production

Render a narrated MP4 with Hindi text-to-speech and SRT subtitles using tools installed with the backend.

MP4 + SUBTITLES
03◉

Review before publishing

Prepare content, review it, and approve it before manual publishing. Manual YouTube uploads are private by default.

CREATOR CONTROL
04↗

YouTube, with your consent

Authorize the Google account you choose through OAuth. The app uses YouTube Data API v3 to read channel details and upload video content.

How the integration works →

Optional scheduled publishing

A separate daily Bollywood-news scheduler can publish publicly at a configured time. It is off by default and requires explicit local configuration.
